# Một Cuộn — Bộ film của đời bạn

A small Vietnamese-language film-photo workspace prototype for collecting moments, trying film-inspired color grades, grouping memories, and exporting story layouts.

## Run locally

This is a static HTML app. Open `index.html` in a modern browser, or serve the directory with any static web server.

## Features in this prototype

- Sample photo gallery with search, filters, and favorites
- Local image upload and drag-and-drop
- Film-inspired looks (Portra, Golden, Mono, Moss) and adjustable color/grain controls
- PNG export for edited photos and 9:16 story layouts
- Memory timeline and light/dark appearance

## Current limitations

- Prototype only: no account system, backend, or cloud photo storage.
- Uploaded images and UI state are held in the current browser session; reloading may reset the gallery.
- The timeline currently groups photos with sample categories rather than user-created albums.
